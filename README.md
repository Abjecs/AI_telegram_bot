# 🤖 AI Telegram Bot

Умный Telegram-бот на базе **GigaChat** с большим набором функций.

## ✨ Возможности

### Основные
- 🧠 **Стили общения**: Стандартный, Шутник, Нейрохам, Философ, Поэт, Эксперт
- 🌐 **Переводчик** на множество языков через GigaChat
- ⏰ **Напоминания** с гибким форматом времени
- 💬 Умные ответы в личных чатах с учётом выбранного стиля

### Поиск и информация
- 📰 Новости по запросу
- 🌤 Погода
- 💱 Курсы валют и конвертация
- 📈 Криптовалюты
- 📄 Анализ документов (PDF, DOCX)

### Развлечения
- 🎮 Викторина с рейтингом
- 🎰 Казино (кости, рулетка)
- ❌⭕ Крестики-нолики с ботом
- 🖼 Генерация мемов

### Файлы и группы
- ☁️ Облачное хранилище файлов
- 👥 Групповые функции: приветствия, триггеры, статистика, автоочистка

### Админка
- Роли пользователей (admin / vip / standard / test / banned)
- Статистика, история, бан/разбан
- Резервное копирование БД

## 🚀 Быстрый старт

1. Клонируй репозиторий:
```bash
git clone https://github.com/Abjecs/AI_telegram_bot.git
cd AI_telegram_bot
```

2. Установи зависимости:
```bash
pip install -r requirements.txt
```

3. Создай файл `.env` (или задай переменные окружения):
```env
TELEGRAM_TOKEN=твой_токен_бота
GIGACHAT_CREDENTIALS=твой_ключ_gigachat
DATABASE_URL=postgresql://user:pass@host:5432/dbname
AUTH_PASSWORD=надёжный_пароль
ADMIN_USER=admin
ADMIN_PASS=надёжный_пароль_админки
```

4. Запусти:
```bash
python bot.py
```

Бот использует webhook (удобно для Render / Railway / VPS).

## 📁 Структура

| Файл | Описание |
|------|----------|
| `bot.py` | Основной код бота |
| `admin_app.py` | Админ-панель (FastAPI + SQLAdmin) |
| `requirements.txt` | Зависимости |
| `Procfile` | Для деплоя |

## 🛠 Технологии

- Python 3.10+
- python-telegram-bot
- GigaChat API
- asyncpg + PostgreSQL
- FastAPI + SQLAdmin (админка)
- aiohttp

## 📝 Примечания

- Бот монолитный — для продакшена рекомендуется разбить на модули.
- GigaChat вызывается при каждом сообщении в личке (можно добавить историю диалога).
- Не забудь сменить дефолтные пароли.
